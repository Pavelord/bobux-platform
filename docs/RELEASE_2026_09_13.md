# Lua runtime and community reward release

Server-owned, once-only community reward: verified badge and lifetime TBC for
the ten account IDs resolved from pavelord, denchiz, Master_Void, Insar43k,
oxlpekxx, pondev, vorexx, stickmasterluke, zsertok and Не знающий. The login dialog has one claim button. Claims are authenticated,
transactional and idempotent. TBC daily currency follows the existing catalog
(38 Boblox/day); no expiry. Paid sales remain disabled. Public profile badges
are derived from the server ledger, never accepted from client profile fields.

Windows 32/64, Linux 64 and Android ARM native Lua callback lifetime fixes;
actual Lua execution is now a mandatory packaged-game release gate. See
LUA_NATIVE_RUNTIME.md for the source patch and rebuild procedure.

Imported-place compatibility improvements include table writes, legacy aliases,
Luau control flow, stored-object script startup, surface assemblies, deferred
assembly splits, non-colliding projectile touches, heavy-body player collisions,
legacy Sound playback and face-specific tiled part surfaces.

Natural Disasters 2011 is **not yet verified end-to-end**. Meteor, flood,
thunderstorm and fire completed in accelerated diagnostic runs. Tornado's
mass-destruction performance remains to be verified after deferred assembly
splitting; tsunami and complete multiplayer damage/respawn cycles are still
outstanding. Do not advertise 100% Roblox compatibility.

Bundled map dependencies were retrieved from Roblox assetdelivery endpoints
`https://assetdelivery.roblox.com/v1/asset/?id=ID`: image 1008744 and legacy sounds
12221990, 12222152, 26723422. They are referenced by the user-supplied 2011 place.
Unavailable/empty texture references have not been replaced with fabricated art.
