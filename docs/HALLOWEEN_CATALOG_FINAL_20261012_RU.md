# Каталог Halloween 2026: финальная проверка

Постоянные ID аксессуаров и право владения не менялись. Названия в API и клиенте: `Coffin Gift Box - Halloween` и `Pumpkin`. Только эти два аксессуара получают оранжевую плашку `Halloween 2026` в каталоге, Avatar, Inventory, профиле и поздравлении. Обычная зелёная `LIMITED` остаётся для остальных предметов.

Плашка Хеллоуина на Home открывает сразу страницу гроба внутри Catalog. На ней один бесплатный предмет, настоящее 3D-превью и получение до конца 30 октября по Москве. До Хеллоуина текст страницы и описание гроба в API не раскрывают тыкву. Выдача награды и поздравление с Pumpkin сохранены на 31 октября, 00:00 по Москве, только для владельцев вовремя полученного гроба.

В Godot Editor получение и примерка работают как локальный предпросмотр: они не добавляют предметы в серверный или сохраняемый клиентский инвентарь. Экспортированный клиент обращается к `/api/rest/v1/rpc/halloween_event`; только этот API подтверждает получение. Ошибка сети сохраняет доступное превью и предлагает повторить проверку.

Гроб подгоняется к верхней границе настоящей округлой головы, а нижняя точка импортированной модели становится опорой. В графической проверке нижняя граница гроба — `4.48484`, верхняя граница головы — `4.46547`: пересечения нет. Pumpkin скрывает базовую голову, находится по её центру и сохраняет свечение. При снятии возвращается исходная голова.

Отдельно исправлен ключ кэша подготовленной одежды: после замены или восстановления файла по прежнему пути клиент не показывает старую текстуру. Исходный декодированный файл разделяется между всеми областями одежды; лимиты кэша не ограничивают число надетых вещей. Подняты версии кэша превью каталога и портретов друзей.

Пройденные проверки Godot 4.7:

- `validate_halloween_catalog.gd`: desktop/480×800, переход настоящей кнопкой Home, один предмет, правильная плашка, отсутствие спойлера, отсутствие выхода за ширину страницы, кнопка получения достижима прокруткой.
- `validate_halloween_accessories.gd`: реальные текстуры GLB, гроб над округлой головой, тыква поверх головы, свечение, восстановление головы после снятия. Headless и графический запуск.
- `validate_halloween_greeting.gd`: граница московской полуночи, один показ на аккаунт, отсутствие обещания предмета без права на него, новая плашка.
- `validate_avatar_attachment_cache.gd`: восемь аватаров делят один HTTP-запрос и один разбор GLB; освобождение первого аватара не срывает остальных; HTML/обрезанный GLB исправляются; скрипты, материалы и независимое состояние импортированной модели сохраняются.
- `validate_avatar_texture_repair.gd`: исходный decode разделяется между 12 областями; замена PNG на WebP по прежнему пути обновляет одежду; HTML отвергается; восстановленный файл доступен без ожидания таймера; фоновая повторная попытка завершается.
- `validate_avatar_inventory_retry.gd`, `validate_lobby_network_retry.gd`: ошибка 503 не удаляет образ и видимых друзей, данные восстанавливаются в фоне.
- `validate_avatar_responsive_halloween.gd`, `validate_mobile_ui_scroll.gd`: портрет/альбом, ширина сетки, отсутствие вложенной ловушки прокрутки; свайп отменяет кнопку Play, обычное нажатие проходит.
- `validate_seasonal_theme.gd`: круг портрета сохраняется, тема восстанавливается, обычная LIMITED не перекрашивается.
- `validate_lobby_image_decoding.gd`: PNG/JPEG/WebP по сигнатуре, неверные расширения, удаление повреждённого кэша и восстановление.
- `validate_profile_update.gd`: 45 проверок профиля и мобильной компоновки, включая новую плашку.

`halloween_event.test.mjs` и `halloween_routes.test.mjs` проходят: авторизация, конкурентные запросы, неизменная дата получения, перезапуск API, граница Москвы, защита от подделки времени/владения и обхода через обычный каталог.

Снимки для проверки находятся в `.codex-tmp/final_event_catalog_desktop.png`, `final_event_catalog_mobile.png`, `final_event_catalog_mobile_scrolled.png`, `final_event_accessories.png`. Это графические запуски проекта на ПК, мобильная компоновка проверена размером окна. Проверку APK на физическом телефоне и проверку опубликованного сервера выполняет основной агент отдельно.

Скриптовых ошибок в последних запусках нет. Графический процесс фикстуры каталога иногда сообщает о 1–2 RefCounted при завершении; в перечисленных остальных headless проверках такого предупреждения нет. Этот пункт не является подтверждением отсутствия утечек в долгой игровой сессии.

## Первичная раскладка после трейлера на Huawei

На физическом Huawei обнаружена огромная плашка Home сразу после первого трейлера. Причина — обычный `Panel` копировал в свой постоянный минимум высоты временный минимум `MarginContainer`, рассчитанный до назначения ширины тексту. Переход на другую вкладку исправлял раскладку, но первый показ оставался растянутым. Плашка заменена на `PanelContainer`: измерение и назначение размеров теперь выполняет обычная контейнерная раскладка Godot, ручное копирование высоты удалено. Масштаб всего приложения не менялся.

`validate_halloween_banner_layout.gd` проходит при физическом окне `2000×1200`, исходном canvas `1280×720` и `CONTENT_SCALE_ASPECT_EXPAND` — логический viewport `1280×768`, как на Huawei. Фикстура сначала создаёт скрытый и остановленный Lobby, затем раскрывает его, повторяя состояние во время первой премьеры. Высота баннера — `122`, приветствие и Friends доступны сразу. Дополнительно проверены возврат из Avatar, узкий портрет (`212` по высоте, обе кнопки внутри) и широкое окно телефона `2340×1080`. Снимки: `.codex-tmp/final_event_home_huawei_canvas.png`, `final_event_home_portrait_banner.png`, `final_event_home_phone_canvas.png`. Повторную проверку в пересобранном APK на физическом Huawei выполняет агент Android QA.
