# A3: production slice EnumItem на границе VM

15 октября 2026. Статус базового slice и дополнительной защиты cyclic inputs **PASS_MINIMAL_OPT_IN_SLICE**. Это минимальное включение по `enum_profile="RobloxParity.EnumItem"`, не завершение A3 или всего Humanoid parity.

`start_script` и активный scheduler path `run_script` принимают профиль как runtime option. Отсутствующий профиль оставляет прежний `ExistingNumericEnums`; null, пустая/неизвестная строка и неверный тип отклоняются до очереди и выдачи runtime ID. Профиль сохраняется при deferred compilation и в диагностике retained runtime.

Единственный изменённый существующий production файл — `autoload/lua_script_engine.gd`. Его исходное dirty состояние сохранено в `.codex-tmp/character_parity/pre_vm_integration/lua_script_engine.gd`, SHA256 `5f6bc6f95391354f5aaaefc8c97adf07046a7c213a99799731275a7f6e4f8ca9`. Соседние `vm_boundary_only.patch` и `manifest.json` отделяют новые изменения от прежних незакоммиченных изменений. Line endings CRLF сохранены. Защищённые файлы, native C++, исходники режимов и registry kernel этой правкой не изменяются.

Новый `addons/roblox_runtime/enums/roblox_enum_vm_boundary.gd` адаптирует четыре метода Humanoid: `GetState`, `ChangeState`, `GetStateEnabled`, `SetStateEnabled`. Внутренний wrapper, мотор, Node metadata и текущие RPC используют прежние scalar IDs. Typed getters и события возвращают singleton EnumItem конкретного VM registry. Два VM используют один BobuxInstance и BobuxEvent, но собственные метатаблицы и weak-key map сигнатур событий.

`StateChanged` и `StateEnabledChanged` конвертируются один раз до task dispatch или заполнения Wait. Поддержаны colon/dot, извлечённые Connect/Once/Wait и lowercase connect/wait для typed signals. Raw native index сохранён до установки shim, поэтому обращение helper к Connect/Once не рекурсивно. Профиль остаётся в вызывающей VM при require, coroutine и task. Registry и adapter принадлежат LuaAPI metadata. Adapter хранит WeakRef connections, периодически удаляет истёкшие/отключённые записи и отсоединяет живые connections до остановки VM, включая listeners на Humanoid вне поддерева Script.

Из native coercion run `c475020d-1687-4cb5-9b53-2ecbe4d5a2f7` Studio 0.742.0.7421053 поддержаны canonical EnumItem/number/name, измеренная положительная fractional truncation, missing/nil arity, wrong-domain и основные invalid-input errors, bool inputs true/false, измеренные `'false'` и numeric 0. Для enabled-state методов unknown/full/numeric state strings теперь принимаются как native no-op с getter=true; canonical flags и события не меняются. Wrong receivers дают измеренную ошибку до проверки аргументов. Другие bool casts и noncanonical physical ChangeState остаются **not implemented**. Это ограничение opt-in slice, а не заявление об их parity. Новые наблюдения Studio 0.743 рассматриваются отдельно до сравнения версий.

Enum namespace содержит десять исследованных доменов / 99 canonical items; kernel r04 имеет 69 PASS. Статический namespace count изменился с 648 в Studio 0.742 до 651 в Studio 0.743; полным namespace этот subset не является. Material, AnimationTrack.Priority и остальные enum properties требуют отдельных typed boundaries; наличие namespace ещё не делает их setters/getters совместимыми. CameraType проверен отдельным последующим slice ниже. `GetState` не маскирует физический fresh-Humanoid gap (backend Running против native None).

Tagged EnumItem wire codec и capability negotiation **OPEN**. Opt-in VM отклоняет EnumItem в RemoteEvent/RemoteFunction аргументах (включая nested tables/keys и извлечённые методы) до старой сериализации, которая иначе превращает Object в nil. Нейтральные методы Instance не блокируются. Профиль не включён по умолчанию и не предназначен для опубликованного сервера до wire/corpus regressions.

Проверка источников `python tools/character_parity/check_enum_vm_sources.py` компилирует собственный объединённый shim/prelude/contract официальным Luau CLI 0.742 и обновляет scoped diff. Это не Godot runtime PASS.

Функциональный валидатор `tools/character_parity/validate_enum_vm_boundary.gd` использует настоящий player.tscn/Humanoid, две реальные VM, shared cached wrapper/event, require cache, tasks/coroutines/yield, canonical state methods, typed Connect/Once/Wait/extracted/lowercase, trailing nil, Stop/GC и deferred profile. Он не использует PropertyFixture. На Godot 4.7 и Luau 0.719 получены **34 PASS / 0 FAIL при каждом порядке создания VM**, **40 PASS игрока**, **16 PASS NPC**, exit 0. Есть реальный вложенный callback B→A→B, проверка post-Disconnect emission и 256 Once callbacks с cooperative yields; владелец после churn держит только 19 WeakRef slots. Все результаты, source hashes и неудачные development runs сохранены в `tests/roblox_humanoid/phase_a/enum_vm_boundary_20261015/` с неизменяемым manifest.

При разработке выявлен и исправлен crash: передача cyclic Lua table в native classifier рекурсивно конвертировала таблицу до проверки. Теперь remote payload обходится в Lua, classifier вызывается только для userdata; таблицы в typed Humanoid arguments отклоняются до native conversion, ignored extra arguments не конвертируются. Fail run r02 сохранён отдельно. Кроме того, fixture использует raw userdata identity для общего BobuxEvent: generic native Object `__eq` пока возвращает false и не исправлялся этой правкой. Это отдельный OPEN пункт.

Последующий независимый review обнаружил дополнительные пути той же конвертации: operands/error formatting, Enum method wrong receivers/arguments/ignored extras, missing bool у SetStateEnabled, readonly writes, member keys и enum call. Lua guards теперь проверены отдельно: только userdata передаются classifier; типы/arity проверяются до tuple conversion; заведомо игнорируемые аргументы и readonly replacement не передаются native bridge. Для неподтверждённых nonstring keys, calls и `%`/`^`/`//` возвращается явное partial error. Новый cyclic contract выполнил все **48 assertions**; r13/r14 дали **36 PASS / 0 FAIL в каждом порядке VM**. Новый manifest: `tests/roblox_humanoid/phase_a/enum_vm_boundary_cyclic_20261015/manifest.json`; прежний manifest с 34 проверками каждого порядка не переписан.

Свежий последовательный runner дополнительно дал PASS для ядра EnumItem, player 40, NPC 16, Luau scheduling, native callback guard и property cache. Первые два VM запуска runner содержат FAIL только из-за неверного ожидания метки ошибки сравнения userdata/table: Luau 0.719 отклоняет mixed types до __lt/__le. Ожидание исправлено как собственный VM safety test, не как доказательство native Roblox error-label parity; эти неудачные логи сохранены. Baseline checker также заметил перемещение одной неизменной строки clear_color внутри `project.godot`; diff отдельно просмотрен, значения настроек не менялись, файл не исправлялся. После явного allow этого проверенного пути protected baseline PASS; три защищённых файла и исторический empirical hash совпадают.

Новое native наблюдение `481ea197-ed76-4972-b05e-7a875c3fc888` (Studio 0.743) содержит 91 случай методов/receiver/arity и 12 событий; SHA-256 `22772eaa9965b6711656ab67f231c440c8a9dbcaca57b3e990824af9bdb28b9e`. Opaque/full/numeric strings для enabled flags оказались no-op с getter=true и нулём событий в двух Heartbeats; canonical Running/item/number меняют флаг и дают typed события. [Производный анализ](C:/robloxclone/tests/roblox_humanoid/phase_a/2026-10-15-studio-humanoid-edges-run01.analysis.json) отделён от реализации: enabled-state no-op и receiver coercion уже включены в opt-in профиль и проверены отдельными 95 assertions; остальные неиспытанные casts остаются partial. ChangeState physics в unparented fixture NOT_OBSERVABLE.

Прежние network regressions для legacy ещё нужны перед релизом; wire profile остаётся закрыт для EnumItem. Исторические 48 PASS / 5 FAIL / 18 SKIP calibration не переписываются. Полнота enum namespace и native noncanonical coercion не получили PASS из-за прохождения этого slice.

## Последний snapshot namespace safety

`tests/roblox_humanoid/phase_a/enum_vm_boundary_namespaces_20261015/manifest.json` сохраняет 38 PASS в обоих порядках VM, 94 cyclic assertions и 95 method-edge assertions. Дополнительно закрыты Enum/Enums operands и nested/cyclic RemoteEvent payloads с namespace userdata; прежний guard только EnumItem был недостаточен. ## Последующий CameraType consumer

Свежий `tests/roblox_humanoid/phase_a/enum_vm_boundary_camera_20261015/manifest.json` сохраняет **43 PASS / 0 FAIL в каждом порядке VM**, 594 CameraType assertions и прежние 94 cyclic / 95 Humanoid method-edge assertions. Применены все 32 native CameraType input rows из run `c475020d-1687-4cb5-9b53-2ecbe4d5a2f7` по четырём маршрутам: обычное присваивание, явный `__bobux_set`, colon SetProperty и bound-dot SetProperty. Проверяются настоящая CurrentCamera под SpringArm и свежая Camera3D, typed getter, сохранение scalar metadata для соседней numeric VM, legacy backend representations без переписывания при чтении, отказ invalid/cyclic writes без изменения metadata/pose и реальные Scriptable/Custom side effects. Scheduled require/task fixture отдельно сохраняет профиль и guard после yield; существующий rewriter оставляет CameraType обычным __newindex, новые rewrite правила не добавлены.

Это не parity всех восьми camera algorithms или native Changed ordering. Два development parse failure logs сохранены: неявный Variant у numeric_string в GDScript adapter исправлен explicit int, raw native cases не менялись. Полный последовательный runner `20261015T210440Z-1d6efc` прошёл 12 групп (Python 25+64, kernel 69, оба VM, player 40, NPC 16, scheduler/callback guard/property cache и baseline). После уточнения только report labels свежие VM reports получены в `20261015T210707Z-61c88a`. Все source hashes и snapshots сохранены, production профиль остаётся opt-in.

Material backend и физические свойства не объявляются готовыми: generic setter пока обновляет только metadata. Archival snapshots/raw data исключены из Godot import/export через `.gdignore`; валидаторы читают их через FileAccess, а не ResourceLoader. Карты, видимый персонаж, native C++ и защищённые файлы не меняются.
