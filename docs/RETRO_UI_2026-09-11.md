## Превью каталога

Обработано **275 записей**: 186 предметов аватара (72 рубашки, 45 штанов, 69 аксессуаров-моделей) и 89 моделей. Все 275 получили PNG после повторной загрузки временно недоступных источников. У одной старой записи `model_1780279171` ссылка указывала на EXE: она не загружается как модель; превью построено из сохранённого в записи цилиндра. Геометрия отсутствующего mesh не заменяется кубом.

Отдельный SubViewport, освещение, белый фон, ортографическая камера по фактическим границам геометрии, 384×384. Ключ кэша зависит от исходных визуальных данных, а не лайков или владения. Файлы: `.codex-tmp/rebuilt_catalog_previews/*.png`, отчёт `results.json`; кэш клиента: `user://catalog_previews/v3`. Генератор: `tools/rebuild_catalog_previews.gd`, повторный запуск продолжает успешную партию. Входные аудиты находятся в `.codex-tmp/*_preview_audit.json`; это локальные снимки общедоступных записей, не часть релиза.

Новые изображения пока **не загружены на VPS**. Новый клиент строит их из серверных моделей/текстур и кеширует локально. Серверные оригиналы не переносятся в репозиторий. При отдельном релизе можно опубликовать подготовленные PNG как статические превью, чтобы не рендерить их на каждом устройстве.

## Messages и оценки

`services/bobux_api/social_store.mjs` — приватная SQLite-база (`BOBUX_SOCIAL_DB`, по умолчанию `data/social.sqlite` относительно рабочего каталога API; держать вне публичного storage). Два индекса сообщений, пагинация по последовательному номеру, до 2000 символов, 30 новых сообщений в минуту, ключ повторной отправки. Доступ требует авторизации и действующей дружбы; sender берётся из токена. Текст рисуется обычным Label, а не исполняемым HTML/BBCode.

Клиент: список друзей, история, загрузка предыдущих сообщений, отправка Enter/кнопкой, опрос открытой беседы раз в 5 секунд, сохранение текста при ошибке. Нет обещания push-уведомлений, сквозного шифрования или модерации: они не реализованы.

Оценки: один голос +1/-1 на пользователя и опубликованную карту, смена голоса обновляет запись. Старые поимённые лайки карт переносятся при запуске сервера, повторный перенос безопасен. Суммарные старые счётчики без поимённых записей не выдаются за проверенные голоса.

На текущем старом VPS новые маршруты ещё отсутствуют: переписка/голосование становятся доступны пользователям после релиза API. Локально проверены HTTP и интерфейс Godot; реальные сообщения другим пользователям не отправлялись.
