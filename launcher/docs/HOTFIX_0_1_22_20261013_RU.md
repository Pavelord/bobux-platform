# Лаунчер 0.1.22 / build 24 — 13 октября 2026

Опубликован отдельным обновлением лаунчера. Игра остаётся 0.1.53 / build 58;
Android, API и работающие комнаты при этой публикации не перезапускались.

## Исправления

- После самообновления новое окно явно показывается и получает фокус, включая
  переход со старой версии, которая запускала преемника с `SW_HIDE`.
- Одновременно обновление выполняет один экземпляр. Повторный запуск передаёт
  фокус уже работающему окну; защита действует и во время передачи управления
  от старого процесса помощнику самообновления.
- Новый помощник ждёт подтверждение готовности нового лаунчера. При неудаче
  восстанавливает предыдущий EXE и открывает окно восстановления.
- Полностью скачанный архив сохраняется при блокировке переименования,
  проверки или установки. Повторяется локальная операция, а не полная загрузка.
- Заблокированный архив отличается от архива с неправильной контрольной суммой.
- Устаревший манифест резервного зеркала не понижает установленную версию.
- Восстановление и самообновление сохраняют состояние и подробности ошибки.

- Реальный ZIP игры build 58: 262 829 621 байт, одна полная загрузка через
  32 диапазонных запроса. Повторная установка после снятия блокировки использует
  сохранённый архив. Установленный EXE прошёл проверку native Luau.
- 17 проверок старых зеркал и межпроцессной защиты прошли.
- Фактический Windows EXE проверен при скрытом старте, успешной передаче
  управления, повторном запуске в промежутке передачи и откате без подтверждения.
- Проверка сервера и публичных артефактов после публикации: 57 проверок, PASS.
- После публикации проверен переход с фактического EXE build 23 через публичный
  сервер: один запуск, загрузка нового лаунчера, видимое окно build 24 и запуск
  установленной игры build 58. Повторно открывать лаунчер не потребовалось.
