# Halloween launcher — 10 октября 2026

Проверки и варианты восстановления дополнены 11 октября.

## Дизайн и возврат обычного оформления

Лаунчер использует тёмную карточку, оранжевую шкалу, оригинальное праздничное
лого пользователя и прозрачную иконку. На фоне медленно движутся искры и две
летучие мыши; перерисовка фона ограничена 20 кадрами в секунду. Распаковка большого
встроенного PCK и проверка файлов происходят в рабочем потоке, поэтому интерфейс
продолжает отвечать. Для интерфейса 2D используется OpenGL Compatibility без
инициализации Vulkan; частота всего окна ограничена 60 кадрами в секунду.

Обычные assets в `launcher/assets/branding/` сохранены. Новые находятся отдельно
в `launcher/assets/branding/halloween/`. `launcher/theme` в `project.godot`
принимает `auto`, `halloween` и `classic`. `auto` включает оформление в октябре
по московскому времени, после октября возвращает старый интерфейс. Для локальной
проверки можно задать `BOBUX_LAUNCHER_THEME=classic` или `halloween`.

Windows-иконка файла EXE фиксируется при экспорте. Для следующего обычного релиза
нужно вернуть `application/icon` в `launcher/export_presets.cfg` к
`res://assets/branding/bobux_app_icon.ico`; исходная иконка не перезаписана.
Иконка окна выбирается автоматически вместе с темой.

В сезонном оформлении кнопки и карточка имеют тонкую границу и углы до 4 пикселей,
в духе интерфейса 2016 года. Сохранены исходные цвета и изображения обычной темы;
её отступы слегка уменьшены, чтобы сообщения об ошибках помещались в окно.

## Загрузка обновления

В исходном коде был общий дедлайн HTTP-запроса в 120 секунд. Если зеркало
игнорировало Range и возвращало весь ZIP, медленная загрузка обрывалась несмотря
на получение данных; цикл запускал целую загрузку повторно до восьми раз. Это
воспроизведено локальным HTTP-сервером с пропорционально уменьшенным дедлайном.
Живой основной сервер сейчас отвечает на Range кодом 206; воспроизведение
покрывает также зеркала без Range и прерывание соединения.

Исправления:

- Ответ HTTP пишется прямо на диск вместо накопления большого ZIP в памяти.
- Вместо дедлайна всей передачи используется 45 секунд без новых байтов.
- Размер диапазона увеличен с 512 КБ до 8 МБ: ZIP build 54 требует около 30
  диапазонов вместо 468 отдельных запросов.
- Content-Range, размер, SHA-256, EXE и необходимые файлы Luau проверяются перед
  установкой. Ответ 200 на возобновление заменяет частичный файл, а не дописывает
  полный ZIP к его началу. Повреждённый ответ не скачивается восемь раз с одного
  зеркала.
- Сохранённый проверенный файл используется повторно. Утерянная метка версии
  восстанавливается только после сверки содержимого установленной игры.
- Защита от одновременного запуска двух update flow, кнопки «Пауза» и
  «Продолжить»/«Повторить».
- После 100% загрузки шкала остаётся полной; явно показаны проверка, распаковка
  и установка. Прежний сброс шкалы до 82% мог выглядеть как повторная загрузка.

После ошибки доступны «Повторить» и меню «Варианты». Повтор использует сохранённые
диапазоны; «Переустановить игру» сохраняет пригодный архив, проверяет распакованные
файлы и только затем заменяет игру. «Начать загрузку заново» очищает только
временные каталоги обновления. Установленная игра и профиль сохраняются до
успешной проверки новой установки. В меню также есть папка установки. Эти действия
блокируются во время уже запущенного обновления; при паузе доступно «Продолжить».
Сообщение об ошибке сохраняет достигнутый прогресс, полные детали есть в подсказке.

несколько диапазонов, продолжение с произвольного байта, игнорирование Range,
неверный диапазон, неверный hash, разрыв связи, паузу, повторное продолжение,
реальную ZIP-установку и повторный запуск. Повторный запуск выполнил второй
запрос манифеста и второй запуск игры, но ZIP был запрошен только один раз.

Повторная проверка 11 октября прошла после добавления восстановления: медленный
HTTP 200, Range/возобновление, повреждённые ответы, пауза и повторная установка.
Для неверного hash и неверного диапазона выполнено по одному запросу без цикла.
На графическом QA обычная и сезонная темы вместе с кнопками восстановления
помещаются в окно 760×430. Проверка PE-ресурсов фактических EXE лаунчера и
установщика показала шесть изображений иконки, байт в байт совпадающих с
хеллоуинским ICO; эту проверку нужно повторять после финального экспорта.
