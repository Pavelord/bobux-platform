# Roblox Audio Pack (2018 client archive)

This folder contains audio files from an archived Roblox Windows client build (2018), collected as a separate local asset pack for Bobux.

## Contents

- `SFX/` — 98 sound effects: movement, jumping, swimming, impacts, UI, tools, and material surface sounds.
- `Music/` — 2 short audio tracks present in the archived client `content/music` folder (`bass.wav`, `ufofly.wav`).

## Source

- Sound effects: https://archive.roblonium.com/Client/Windows/RCCService/unlisted/2018/content/sounds/
- Music: https://archive.roblonium.com/Client/Windows/RCCService/unlisted/2018/content/music/
