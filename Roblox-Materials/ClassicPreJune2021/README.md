# Classic Roblox part textures

This folder contains 18 PNG surface textures from the community collection [All Roblox Part Textures (PRE JUNE 2021)](https://devforum.roblox.com/t/all-roblox-part-textures-pre-june-2021/219437), posted by Younite on the Roblox Developer Forum.

The collection covers classic part surfaces such as brick, grass, sand, rust, aluminium, and wood. It is a community reconstruction, not a Roblox-official texture release. The post author specifically says the aluminium, ice, and plastic colors were recreated as closely as possible. These are single color texture images for parts; they do not include PBR maps or the separate top/side terrain maps.

These files are kept as a reference pack and are not automatically applied by the game.
