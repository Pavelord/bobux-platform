# Classic Roblox part surfaces

`studs.dds` is the original surface atlas copied from the Roblox client installed on this computer (`PlatformContent/pc/textures/studs.dds`). `studs_atlas_preview.png` is a PNG conversion for easy viewing; keep the DDS as the source asset.

The atlas contains the classic square stud, inset/inlet, crossed weld/glue, and alternating universal surface patterns. Roblox documents these as the `Studs`, `Inlet`, `Weld`, `Glue`, and `Universal` surface types: https://create.roblox.com/docs/reference/engine/enums/SurfaceType

This is a texture atlas rather than separate image files for each surface. It is included as a reference asset pack and is not automatically applied by the game.
