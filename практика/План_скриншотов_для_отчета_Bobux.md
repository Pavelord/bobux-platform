# План скриншотов для отчета по практике Bobux

Этот файл нужен как чек-лист для ручной верстки отчета. В код добавлены комментарии `PRACTICE SCREENSHOT`: открой поиск по проекту и найди эти маркеры, чтобы быстро выйти на нужные фрагменты.

## Минимальный набор скриншотов

1. Экран входа/регистрации Bobux.
   Подпись: `Рисунок 1 - Форма авторизации пользователя в клиенте Bobux.`

2. Главное меню или лобби после входа в аккаунт.
   Подпись: `Рисунок 2 - Главное меню платформы после загрузки профиля пользователя.`

3. PocketBase или административная статистика: профили, карты, предметы, инвентарь, активные серверы.
   Подпись: `Рисунок 3 - Статистика и коллекции базы данных сетевого модуля.`

4. Каталог, инвентарь или профиль в клиенте, где видно, что данные загружаются с сервера.
   Подпись: `Рисунок 4 - Отображение серверных данных в интерфейсе клиента.`

## Куда вставлять в отчет

- Раздел 4: схема архитектуры, главное меню, общая схема сетевого модуля.
- Раздел 5: экран входа, код signup/login на сервере, код sign in/sign up в `CloudAPI`.
- Раздел 6: каталог/инвентарь в приложении, публикация предметов и `My creations`.
- Раздел 7: WebSocket-клиент, handshake комнаты, heartbeat выделенного сервера.
- Раздел 8: PocketBase/admin stats, файл статистики `bobux_network_module_stats_2026-07-03.json`, код `buildAdminStats()`.
- Приложение В: можно оставить полную таблицу плана скриншотов как доказательную карту.

## Что не скринить

- Не показывай пароли, токены, cookies, service key и приватные URL с секретами.
- Не вставляй консоль с ошибками, если они не относятся к демонстрации результата.
- Не показывай чужой заголовок МВЕК из файла-примера: он удален из нового отчета.
